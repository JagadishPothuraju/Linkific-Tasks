# Day 13 — NLP Text Preprocessing and TF-IDF

## Objectives
- Lowercase text
- Tokenize text
- Remove stopwords
- Convert text into TF-IDF vectors
- Inspect and save the output

## Files
- `Day13_NLP_Text_Preprocessing_TFIDF.ipynb`: complete practice notebook
- `outputs/preprocessed_text_dataset.csv`: original and preprocessed text
- `outputs/tfidf_matrix.csv`: TF-IDF features and labels
- `outputs/top_tfidf_terms.png`: visualization of average TF-IDF scores
- `Day13_NLP_Documentation.docx`: report

## Run
Install requirements with `pip install -r requirements.txt`, then open the notebook in Jupyter or Google Colab.
