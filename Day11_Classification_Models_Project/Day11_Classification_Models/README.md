# Day 11 – Classification Models

Train Logistic Regression and Decision Tree classifiers and compare accuracy.

Dataset: Scikit-learn Breast Cancer Wisconsin dataset saved locally in `data/`. Educational use only; not a medical diagnostic tool.

## Files
- `data/breast_cancer_classification.csv`
- `notebooks/Day11_Classification_Models.ipynb`
- `outputs/accuracy_comparison.csv`
- `outputs/observations.txt`
- `visualizations/accuracy_comparison.png`
- `requirements.txt`

## Run
```bash
pip install -r requirements.txt
jupyter notebook
```
Open `notebooks/Day11_Classification_Models.ipynb` and run all cells.
