# Presentation Script

Good morning everyone. Today I am presenting my task on Large Language Models and Hugging Face.

First, I studied the evolution from traditional machine learning to deep learning, transformers, Generative AI, and LLMs. I then explored the Hugging Face Model Hub and reviewed model cards.

For the practical part, I selected three models for three tasks: GPT-2 for text generation, DistilBERT for sentiment analysis, and BART for summarization. I recorded the outputs and compared them using task-specific criteria. For generation, I checked relevance and coherence; for sentiment analysis, I checked the label; and for summarization, I checked coverage and factual consistency.

The main lesson is that models are designed for different tasks, so there is no single model that is best at everything. Availability and outputs can also depend on the inference provider. I documented the experiment in a notebook and prepared it for GitHub. Thank you.
