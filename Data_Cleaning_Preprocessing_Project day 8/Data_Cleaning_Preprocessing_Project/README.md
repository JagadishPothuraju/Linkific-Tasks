# Data Cleaning and Preprocessing with Pandas
**Prepared by:** Jagadish Pothuraju  
**Domain:** Artificial Intelligence and Machine Learning

## Objective
Identify missing values, remove duplicates, standardize column names, convert incorrect data types, and export a cleaned CSV.

## Project structure
- `data/raw_student_data.csv` — raw example dataset
- `notebooks/Data_Cleaning_Preprocessing.ipynb` — step-by-step notebook
- `outputs/cleaned_student_data.csv` — cleaned dataset
- `requirements.txt` — required packages

## Dataset note
The included dataset is synthetic practice data with intentional missing values, duplicates, inconsistent column names, and invalid numeric text. Replace it with a real CSV if required by your internship.

## Run
```bash
python -m pip install -r requirements.txt
jupyter notebook
```
Open `notebooks/Data_Cleaning_Preprocessing.ipynb` and run all cells.
