# Day 3 - Python Data Structures & File Handling

## Learning Objectives
- Learn Lists, Tuples, Dictionaries and Sets.
- Learn reading and writing text files.
- Organize and manage simple data.

## Main Project
### Student Record Management System
A menu-driven Python application that stores and retrieves student records from a text file.

### Features
1. Add Student
2. View Students
3. Search Student by ID
4. Delete Student by ID
5. Exit

### Student Details
- Student ID
- Name
- Age
- Course
- Marks
