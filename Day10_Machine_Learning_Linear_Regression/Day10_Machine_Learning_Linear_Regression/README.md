# Day 10 – Machine Learning Practice: Linear Regression

## Objective
Learn the basic machine learning workflow using scikit-learn: inspect data, split into training/testing sets, train Linear Regression, predict values, and evaluate performance.

## Dataset
`data/study_hours_marks.csv` is a small illustrative synthetic dataset relating study hours to exam marks. It is not real student data.

## Files
- `data/study_hours_marks.csv` — practice dataset
- `notebooks/Day10_Linear_Regression.ipynb` — notebook
- `outputs/test_predictions.csv` — test predictions
- `outputs/model_metrics.csv` — model metrics
- `visualizations/linear_regression_plot.png` — chart
- `requirements.txt` — dependencies

## Run
```bash
pip install -r requirements.txt
jupyter notebook
```
Open `notebooks/Day10_Linear_Regression.ipynb` and run all cells.

## GitHub
Place this folder inside your internship repository as `Day 10`, then run:
```bash
git add "Day 10"
git commit -m "Add Day 10 Linear Regression practice"
git push origin main
```

## Caution
The dataset is synthetic and small. Results are for learning only and should not be treated as real-world model performance.
